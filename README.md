# NOVA WING

Космический шутер с видом сверху.

В архиве два варианта:

1. **`play/`** — готовая игра, Node не нужен
2. **исходники** — полный проект (React / Vite / TanStack Start)

## Быстрый запуск (готовая игра)

Нужен Python 3 (обычно уже есть на компьютере):

```bash
cd nova-wing/play
python3 -m http.server 5500
```

Windows (если `python3` нет):

```bat
cd nova-wing\play
python -m http.server 5500
```

Откройте в браузере [http://localhost:5500](http://localhost:5500).

Папку `play` нельзя просто дважды кликнуть как `index.html` — браузер блокирует модули с диска. Локальный сервер обязателен.

## Полный исходник

Нужен [Node.js 22](https://nodejs.org/) или новее.

```bash
cd nova-wing
npm install
npm run dev
```

Откройте [http://localhost:8080](http://localhost:8080).

`node_modules` в архив не входит — зависимости ставятся командой `npm install`.

## Управление

- **WASD / стрелки** — полёт
- **Мышь** — прицел, клик или пробел — огонь
- Удерживайте курсор, чтобы тянуть корабль за указателем
- **Esc / P** — пауза
- На телефоне: левый стик двигает, правая половина стреляет

Рекорды хранятся в браузере (`localStorage`).
